# 세무칼럼 직접 수정 방법 (관리자용)

이 파일은 밑줄(_)로 시작하므로 홈페이지 칼럼으로 발행되지 않는 안내 문서입니다.

이 `content/` 폴더의 `.md` 파일이 세무칼럼의 **원고(원본)** 입니다.
GitHub에서 이 파일을 고치면, 배포 시 자동으로 홈페이지에 반영됩니다.

## 수정 방법
1. github.com/tax8980-coder/musical-train → `content` 폴더 열기
2. 수정할 칼럼의 `.md` 파일 클릭 → 오른쪽 위 **연필(✏️) 아이콘**(Edit) 클릭
3. 내용 수정
   - 맨 위 `--- ... ---` 사이(프런트매터): `title`(제목), `summary`(요약), `tags`(태그), `date`(날짜) 수정 가능
   - 그 아래: 본문. 마크다운으로 작성 (`# 제목`, `**굵게**`, 표 등)
4. 아래 **Commit changes** 클릭 → 1~2분 뒤 홈페이지에 반영

## 주의
- `slug`, `notion_id` 줄은 **건드리지 마세요**(글 주소·식별자). 바꾸면 링크가 깨집니다.
- 파일 이름을 `_`(밑줄)로 시작하면 발행에서 제외됩니다(이 안내문처럼).
- 노션에서 기존 칼럼을 수정해도 홈페이지에는 반영되지 않습니다(동기화는 새 글 추가만 함).
  기존 글 수정은 **반드시 이 `.md` 파일**에서 하세요.
- 새 칼럼은 노션에 쓰면 매주 월요일 자동으로 추가됩니다(또는 여기 `.md`를 직접 추가해도 됩니다).
