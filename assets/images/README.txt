이미지 교체 슬롯
===============================================================

아래 경로에 파일을 넣으면 자동으로 적용됩니다. (파일명·확장자를 정확히 맞춰주세요)

- hero.jpg    : 히어로 우측(모바일 하단) 이미지. 권장 1200x900 (4:3)
- profile.jpg : 대표 세무사 프로필 이미지.       권장 600x800 (3:4)
- og.png      : 카카오톡/SNS 공유 미리보기 이미지. 권장 1200x630 (제공됨/교체 가능)

[히어로 · 프로필]
파일이 없으면 네이비 그라데이션 + 이니셜 모노그램(지율 / 손)으로 자동 대체됩니다.
이미지는 "성공적으로 로드될 때만" 위에 표시되므로, 경로가 틀리면 조용히 모노그램으로 남습니다.
→ 이미지가 안 보이면 (1) 파일명 철자·확장자, (2) 이 폴더 위치를 먼저 확인하세요.
   JPG가 아니라 PNG를 쓰려면 index.html 의 hero.jpg / profile.jpg 경로도 함께 바꿔주세요.

[공유 미리보기 og.png] — 중요
카카오톡·페이스북 등 공유 미리보기는 다음 3가지가 모두 충족돼야 보입니다.
  1) og.png 파일이 이 폴더에 존재  ← 기본 이미지 제공됨(make_og.py 로 재생성 가능)
  2) index.html 의 [사이트 주소 입력] 을 실제 도메인(https://...)으로 교체
     → og:image 가 절대 URL(https://도메인/assets/images/og.png)로 완성됨
  3) 사이트가 외부에서 접근 가능한 공개 https 주소로 배포되어 있어야 함
     (localhost/127.0.0.1 나 도메인 미입력 상태에서는 미리보기가 뜨지 않습니다)
배포 후 카카오톡 미리보기가 갱신되지 않으면 카카오 캐시 초기화 도구에서 URL을 다시 긁어주세요.
  - 카카오: https://developers.kakao.com/tool/debugger/sharing
  - 페이스북: https://developers.facebook.com/tools/debug/
